# Insight (Windows MVP)

`Insight` 是一本日记，记录你每天每个时间做了什么事，效率如何，心情如何。

`Insight` 是一个时间管理软件，可以直观地看出自己每天/每周的时间分配情况。

`Insight` 是一个自律打卡软件，可以帮助你自律养成好习惯，通过为事件每单位时间设置积分增减，得到正反馈。

`Insight` 是一个科研级别的事件分析工具，可以分析不同事件之间的关联性强度，也可以指导你设计随机对照实验来进行事件的因果性分析。

## 产品目标

围绕“长期记录 -> 数据分析 -> 行为优化”构建价值链，分阶段实现：

1. **基础统计**：频率、时长、趋势、周期分布
2. **关联分析（进行中）**：行为与效率/状态/心情等指标的相关关系
3. **因果探索（后续）**：基于随机化与对照思路的个人实验指导

核心原则：**降低记录成本，提高长期坚持率**。  
没有持续输入，就不会有稳定可信的分析输出。

## 当前范围（MVP）

- 平台：Windows
- 导航结构：`记录` / `统计` / `积分` / `关联性分析` / `方块管理` / `设置`
- 数据模型：`事件方块（模板） + 记录实例`；积分账户 + 积分流水
- 记录规则：允许事件时间重叠（如“写作”和“喝咖啡”）
- 统计口径：频率按记录条数，时长按每条记录独立累计（MVP 不去重重叠时长）

## 关键交互原则

- 先创建方块（名称、分类），再快速复用方块做记录
- 记录流程尽量短：时间 + 效率/状态/心情（支持 `无`）
- 记录过程中支持即时新增方块，避免中断
- 界面设计优先“低认知负担”和“高频输入效率”

## 开发进度（更新于 2026-05-09）

### 已完成

| 模块 | 说明 |
|------|------|
| **主框架** | 左侧导航 + 多页栈；统计/关联页延迟加载以提升首屏响应 |

| **撤销/重做** | 全局多步栈（约 200 步）；`Ctrl+Z` / `Ctrl+Y`；覆盖记录增删改、框选批量删除、积分手动调整、方块 CRUD |

| **测试** | `pytest`：`record` / `correlation` / `points` 流程（当前 5 项通过） |
| **启动与打包** | `LaunchInsight.vbs` / `LaunchInsightDebug.bat`；`scripts/build.ps1` + `run_insight.py`（PyInstaller） |

## 技术栈

- Python + PySide6（桌面 GUI）
- SQLite + SQLAlchemy（本地存储与数据访问）
- pyqtgraph（统计图表渲染）

## 运行方式

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m src.app.main
```

## 测试

```powershell
pytest
```

## 开发调试

生成“当前周”随机测试数据（用于统计页面调试）：

```powershell
python -m src.app.dev.seed_current_week --seed 42
```

保留当前周已有数据并追加：

```powershell
python -m src.app.dev.seed_current_week --seed 42 --keep-existing
```

## 项目结构

- `src/app/ui`：界面（记录时间轴、统计、积分、关联、方块、设置）
- `src/app/services`：业务逻辑（统计、关联、积分、`undo_stack`）
- `src/app/storage`：SQLite 初始化与仓储
- `src/app/domain`：领域模型（记录、方块、关联项目、积分账户/流水、设置）
- `src/app/dev`：开发辅助（如当前周种子数据）
- `docs`：MVP 规格与设计文档
- `tests`：自动化测试
- `scripts/build.ps1`：一键打包脚本
